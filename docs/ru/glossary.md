# Глоссарий

Слова, которыми говорят отчёты и команды Testence, в порядке знакомства.

| термин | значение |
|---|---|
| `ex` | фикстура, которая управляет браузером: записываемые шаги, точные проверки, вход уже выполнен |
| `Target` | как шаг называет элемент: сначала роль и доступное имя, затем label, test id, CSS |
| шаг | одно записанное действие или проверка с предложением `intent` |
| запуск | один `testence run` или сессия pytest; `runs/<id>/` хранит его ledger и packs |
| ledger | `run.jsonl`, журнал запуска только на добавление ([схема evidence](evidence-schema.md)) |
| evidence pack | что оставляет упавшая попытка: снимок страницы, API-трафик, консоль, предложенное исправление |
| oracle | независимое наблюдение, доказывающее результат, обычно чтение API от имени того же пользователя |
| PlanSpec | необязательный файл утверждений и проверок, к которым можно привязать тест |
| claim (утверждение) | одно предложение, которое доказывает тест: субъект, действие, наблюдаемый результат |
| assertion | проверка, привязанная к claim (`assertion_id`, `claim_id`), чтобы доказательство можно было посчитать |
| `verified` | все обязательные assertions, привязанные к тесту, прошли |
| `violated` | assertion упала: продукт не согласен с claim |
| `inconclusive` | evidence не смогло решить (потерян вход, API недоступен, пустой ответ или не JSON) |
| `unverified` | тест выполнен, но ни одна assertion не привязана к claim; это не сбой |
| mocked | запрос, на который ответил `ex.route`; он не дошёл до сервера и ничего о нём не доказывает |
| actor | другой пользователь в том же тесте (`testence_actor`) со своей сессией |
| heal proposal | проверяемое предложение для селектора, который перестал подходить; молча не применяется |
| skill | файл инструкций, который загружает клиент агента (`testence agent install`) |
