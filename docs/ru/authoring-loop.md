# Короткие итерации автора

Полное описание цикла — карта страницы (`testence explore`), область поиска контролов,
прогон ровно одного кейса (`testence debug`), адаптеры ответов, наблюдение исходов,
параллельный прогон и повторное использование браузера — в английской версии
[authoring loop](../en/authoring-loop.md). Здесь — тёплый цикл одного кейса и его замеры.

## Тёплый цикл

```bash
testence watch --warm -w tests -- python -m pytest tests/test_import.py::test_import_name -q
```

Что тёплая итерация сохраняет: интерпретатор Python, импорты pytest и Testence, браузер
и его драйвер (`TESTENCE_WARM_ENGINE=1`; движок закрывается один раз, через
`close_warm_engine`, когда цикл останавливают). Что обновляет: сессию pytest, все
фикстуры, run ID и доказательства, а также контекст браузера: каждый тест начинается с
`reset_session()` без cookies и storage. Модули проекта под наблюдаемыми каталогами
выгружаются перед каждым повтором, поэтому выполняется именно сохранённая правка. Вход
через форму поэтому повторяется на каждой итерации, как и в свежем процессе: он часть
теста. Если вход слишком долгий, сохранённая сессия (`auth: storage-state`, см.
[Аутентификация](auth.md)) открывает каждый новый контекст уже вошедшим.

Каждый прогон печатает код выхода и время:

```text
[watch] run 2 exit 0 in 2.2s
```

Замеры на примерах из репозитория (копия `examples/` с синтетическим приложением во
временном каталоге), Windows 11, Python 3.12.4, `TESTENCE_BROWSER_CHANNEL=msedge`,
headless, на хосте, где одновременно шли другие браузерные наборы. Холодный —
свежий процесс `python -m pytest … --testence-headless` от старта до выхода. Тёплый —
`testence watch --warm -w examples -- pytest … --testence-headless`, между прогонами
модуль теста правится (меняется одна строка `intent`); изменённый intent виден в
`run.jsonl` следующего прогона, и ни один тёплый прогон не запускал браузер.

| Объём | Холодный, свежий процесс | Тёплый 1 | Тёплый 2 | Тёплый 3 |
|---|---|---|---|---|
| `examples/test_login_flow.py::test_login_form_grants_access` | 6,0 с, 7,1 с, 7,2 с | 7,9 с | 2,2 с | 1,8 с |
| `examples` (5 passed, 1 skipped) | от 28,8 с до 172,6 с за шесть прогонов | 26,1 с | 9,1 с | 6,2 с |

Первый тёплый прогон платит тот же старт, что и холодный; со второго итерация всего
каталога примеров укладывается в 10 с, тогда как холодный прогон занимает на этом хосте
не меньше 25 с. Холодные замеры сильно гуляли под параллельной нагрузкой (один холодный
прогон ещё и упал по таймауту 10 с на `goto` локальной страницы `file://`) — это вторая
причина держать браузер: тёплая итерация не повторяет запуск, который нагрузка
замедляет. Принимать результат всё равно нужно свежим процессом.
