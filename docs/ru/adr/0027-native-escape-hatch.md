# ADR-0027: Единственный записываемый выход на прямой Playwright

Статус: accepted (уточняет ADR-0001).

## Контекст

ADR-0001 держит типы Playwright внутри `testence.engine`, чтобы DSL оставался
независимым от движка. Всё, чего DSL не выражал, — работа с canvas, собственный виджет
перетаскивания, сочетание клавиш, API браузера — не имело пути вовсе: команде
приходилось форкать библиотеку или отказываться от теста. Каждый пробел DSL становился
тупиком.

## Рассмотренные варианты

- **Оставить границу абсолютной.** Независимость от движка, но внедрение упирается в
  каждый пробел.
- **Свободно отдавать страницу** (фикстура, возвращающая `Page`). Просто, но незаписанные
  действия размывают evidence и intent шагов, ради которых существует фреймворк.
- **Один явный записываемый шов.** Контекстный менеджер, который отдаёт страницу движка
  внутри шага DSL при наличии capability.

## Решение

`with ex.native("<intent>") as page:` отдаёт `Page` Playwright текущего теста внутри
одного `step` с этим intent. Непустой intent обязателен. Событие `native.used`
фиксирует, что действия внутри не записывались по одному. Падение внутри — упавший шаг
с pack; healing не предлагается. Движки объявляют `browser.native`; движок без неё
отказывает с `UnsupportedCapability` до запуска блока.

## Последствия

DSL остаётся путём по умолчанию и описанным путём; навык автора говорит об этом прямо.
Тесты с `ex.native` привязаны к Playwright. Проверки после блока по-прежнему идут через
DSL, чтобы оракулы и evidence оставались связанными.

## Tripwire

Если `native.used` встречается в большинстве тестов реальных наборов, в DSL не хватает
примитивов, и их нужно добавить (L12), а не расширять шов.
