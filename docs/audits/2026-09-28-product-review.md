## Главные выводы

1. **Тезис и план расходятся.** Тезис ([launch-thesis.md](../en/launch-thesis.md))
   обещает: «UI-тест прошёл, данные не сохранились — Testence это поймал», для
   разработчика с coding-агентом, с первым доказательством за 15 минут. Около половины
   пунктов плана этапа 4 обслуживают миграцию QA-команд на TestOps и ширину раннера. Ни
   один не сокращает «клей» для oracle и не измеряет активацию, хотя именно это — критерий
   провала тезиса («oracle требует столько связывания, что первая ценность > 30 мин»).
2. **На современном SPA главный сценарий не воспроизводится.** Oracle ходит в API с
   cookies и заголовками `AuthContext`; токен из localStorage туда не попадает, и
   проверка на JWT/OIDC-приложении честно, но бесполезно становится `inconclusive`
   (B1, проверено: `api.py:201`).
3. **Есть утечка секрета.** Bearer-токен и Basic-пароль ставятся заголовком на весь
   контекст браузера и уходят на каждый сторонний origin: CDN, аналитику, шрифты (B2,
   проверено: `playwright_cdp.py:1183`, `auth/strategies.py:220`). Для продукта, который
   продаёт маскирование evidence, это блокер.
4. **Ловушки первого дня.** Тест, который просит только `ex`, не логинится, хотя
   документация обещает обратное (проверено: `pytest_plugin.py:1634`). Пример `verify` в
   `auth.md` падает с `TypeError` (проверено). В публичных материалах три разных идиомы
   oracle.
5. **Нет видимого доказательства.** В README нет ни одного скриншота отчёта, нет готового
   CI-шаблона для пользователя, `doctor` молчит 40 с.
6. **Сильные стороны настоящие** и подтверждены всеми углами: oracle по той же сессии с
   ожиданием стабильности (`stability_ms`, `minimum_revision`), ограниченные по бюджету
   pack, heal как ревьюируемый diff с порогом уверенности, детерминированный replay без
   модели, контракты verdict/repair с digest, зрелые CI и supply chain (SBOM,
   provenance, OIDC-публикация), честная документация об ограничениях.

## Вопросы владельцу

1. **Жёсткие ворота тезиса или план.** Тезис требует: 4 из 5 новых пользователей за 15
   минут, прогон в Codex, Claude Code и OpenCode, два внешних воспроизведения. План
   передал это владельцу, а L17 убирает язык ворот из документов. Какой документ
   правильный — нужно записать решением.
2. **Сравнения с конкурентами в README.** Решение 1.1.4 выносит бенчмарки на видное
   место, тезис запрещает сравнительные заявления до проверки на реальных приложениях.
3. **Приоритет миграции TestOps против тезиса.** Предлагается опустить L10 и L11 и
   поднять поиск oracle, L05 (корректность) и L13 (в суженном виде).
4. **Анонимные тесты.** Подтвердить, что `ex` по умолчанию логинится, а анонимный
   режим — явный маркер.
5. **axe-core (MPL-2.0).** Подтвердить подход «скрипт подключает пользователь», как с
   pytest-rerunfailures.
