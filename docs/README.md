# Testence documentation / Документация Testence

- [English](en/README.md)
- [Русский](ru/README.md)

Both language trees have the same structure and describe the same product and
protocol contracts. Обе языковые версии имеют одинаковую структуру и описывают один
и тот же продукт и набор протокольных контрактов.

The shared entry point for any coding agent is [AGENTS.md](../AGENTS.md).

`audits/` and `stages/` hold engineering records: what was checked, when, and what
remains open before a release. They are working documents, not user guides.
